# SiteBio - Plataforma Educacional de Biologia (IFRN)

Projeto final de PPI / Biologia - IFRN.
Desenvolvido por: Lívia Maria, Maria Antônia e Olívia Bezerra.

## Como Executar

1. Instale o Flask:
   ```bash
   pip install -r requirements.txt
   ```
2. Execute a aplicação:
   ```bash
   python app.py
   ```
3. Acesse em seu navegador:
   `http://127.0.0.1:5000`
